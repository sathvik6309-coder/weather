Tools Quick Start

CGD provides tools to view and compare genetic maps, BLAST genomes and reference transcriptomes, view genome annotations in JBrowse, and search interfaces to find and download marker, map, QTL and sequence data.

Browse all tools →

JBrowse 2

A fast, embeddable genome browser for viewing genome assemblies and their annotations. Thirteen genomes from multiple species are available, with Minimap2 synteny tracks alongside marker, QTL and GWAS tracks.

BLAST

Search one or more of your own sequences against CGD genomes and reference transcriptomes. Select a query type — nucleotide or protein — choose a target database and set your search parameters.

CitrusCyc

Metabolic pathway databases generated with Pathway Tools, allowing users to view the pathways present in citrus genomes. CitrusCyc instances are available for C. clementina, C. sinensis, C. maxima and F. hindsii.

MapViewer

Dynamic visualization of genetic maps. Compare linkage groups side by side, follow markers between maps, and link out from any marker to its underlying sequence and QTL evidence.

Synteny Viewer

Built on the Tripal Synteny Viewer, this tool displays the results of Citrus and Liberibacter genome comparisons performed with MCScanX, revealing conserved blocks between assemblies.

MegaSearch

A flexible, filter-driven interface for finding and downloading marker, map, QTL, germplasm and sequence records. MegaSearch supports searching records with empty fields so that partially curated data stays discoverable.

About the Citrus Genome Database

The Citrus Genome Database (CGD) is a USDA and NSF funded resource to enable basic, translational and applied research in citrus. It houses genomics, genetics and breeding data for citrus species and for the organisms associated with Huanglongbing (HLB), the disease complex that represents the most serious threat to citrus production worldwide.

CGD is built and maintained by the Mainlab at Washington State University using Tripal, an open-source toolkit for constructing online genomic and genetic databases on top of the Chado schema. The same platform underpins the wider tfGDR family of tree fruit, nut and specialty crop databases, so data models, search interfaces and tools stay consistent across crops.

Data in CGD includes the Citrus clementina and Citrus sinensis genomes, Ca. Liberibacter genomes, the C. sinensis reference transcriptome (RefTrans), 63 citrus genetic maps, 42,238 markers, 479 QTL, and CitrusCyc pathway databases. All of it is cross-linked — a marker links to its map position, its sequence and any QTL it anchors.
